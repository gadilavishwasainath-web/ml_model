# ML API with Kubernetes

This project demonstrates how to deploy a Machine Learning model as an API using **Flask (Python)**, **GitHub**, and **Kubernetes** (with Minikube or a cloud provider like GKE/EKS/AKS).

---

## 🚀 Features
- REST API built with **Flask** to serve ML model predictions.
- Containerized with **Docker** (optional if using cloud build tools).
- Deployment and Service files for **Kubernetes**.
- Works with **Minikube** (local) or **Cloud Kubernetes clusters**.
